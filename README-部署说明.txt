教学科研工作台 · 教学科研日程版

部署
- 离线使用：解压“教学科研工作台-网页版离线包.zip”，打开 index.html。现代浏览器支持本地 PDF 信息读取。
- GitHub Pages：将“教学科研工作台-GitHubPages发布包.zip”中的全部文件解压至站点根目录后发布。
- 发布包只含网页入口、打包后的程序、PDF.js 本地解析器、许可证和本说明。不含源码、依赖目录、开发缓存或用户数据。

功能
日历（日/周/月）、日程、看板、时间线、并列显示和四象限共用同一任务数据；支持教学科研任务、重点成果、速记和重要文献研读（已读/在读/未读看板、拖拽分区和手动阅读进度）。重要文献可手工录入，或从本地 PDF 尝试提取标题、作者、年份、来源及卷期信息；请复核后保存。原始 PDF 不会上传或留存。

本地数据与登录
默认账户为“万老师”，默认密码由创建者单独提供。工作台数据存放在当前浏览器本地，可使用导出/导入 JSON 在离线与线上浏览器之间迁移。勾选“记住此设备”后，当前浏览器 30 天内跳过登录；密码字段支持浏览器自动填充，是否保存密码由浏览器自行决定。本应用不在 Cookie 中保存明文密码。

隐私范围
这是无需后端的纯静态网页。登录属于浏览器本地访问门槛，数据仍保存在浏览器本机，未做服务器账户认证或数据加密。GitHub Pages 会公开网页程序文件；不要把静态登录当作多用户安全系统，也不要在共享设备上启用记住此设备。需保护敏感研究资料时，请使用个人系统账户、磁盘加密和设备锁屏。
